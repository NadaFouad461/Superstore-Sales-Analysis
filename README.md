# Superstore Sales Analysis Dashboard

## Project Overview
This project presents an interactive multi-page dashboard built using Microsoft Excel to analyze e-commerce sales performance using the Superstore Dataset during the NTI Data Analytics Summer Training Program.

The dashboard provides actionable business insights into revenue trends, order distribution, regional performance, and shipping logistics through interactive visualizations.

## Tools and Techniques Used
- Microsoft Excel: Pivot Tables, Pivot Charts, Interactive Slicers
- Data Cleaning and Preparation: Date standardization, duration calculation, and status classification
- Advanced Formulas: IFERROR, TEXT, SUM, AVERAGE

## Dashboard Key Features and KPIs
- Sales and Revenue Tracking: Total Sales, Average Order Value (AOV), and Order Volumes
- Category Breakdown: Performance analysis across Technology, Office Supplies, and Furniture
- Geographic Insights: Regional order distribution (East, West, Central, South)
- Logistics and Delivery: Shipping Duration and On-Time Delivery tracking
- Interactive Filters: Year, Region, Product Category, Segment, and Ship Mode

## Key Insights
- Revenue Drivers: Technology generates the highest sales revenue among product categories.
- Regional Dominance: The West and East regions account for the highest proportion of total sales.
- Order Logistics: Average shipping duration is approximately 4 days, with high on-time delivery rates across major ship modes.
